# Casual-Game-Hub

An AI-based gesture-controlled casual gaming hub that allows users to play multiple simple games using webcam-detected hand gestures.

## Project Goal
The goal of this project is to build a modular gaming platform where one shared gesture-recognition engine can control multiple casual games such as maze navigation, runner, and fruit-slice style games.

## Planned Features
- Webcam-based hand gesture input
- Shared gesture detection and mapping layer
- Multiple casual games in one hub
- Game launcher system
- Calibration and gesture feedback
- Modular and extensible architecture

## Initial Game Scope
- Maze Game
- Runner Game
- Fruit Slice Game

## Tech Stack
- Python
- OpenCV
- MediaPipe or gesture detection model
- Pygame

## Project Structure
- `app/camera` - webcam input handling
- `app/gestures` - gesture detection, classification, mapping
- `app/games` - individual game modules
- `app/hub` - launcher and shared state
- `app/utils` - helper utilities
